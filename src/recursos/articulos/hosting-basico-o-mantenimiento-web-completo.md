Contratar un hosting es el primer paso para tener una web, no el último. Es fácil confundir «la web está alojada» con «la web está cuidada». Pagas la renovación del hosting cada año y das por hecho que alguien vigila lo demás.

Son dos cosas distintas. Te conviene saber qué cubre cada una para decidir qué contratar y qué te toca hacer a ti.

## Qué cubre un hosting básico

Cumple su función, que es alojar la web:

- **El servidor y sus recursos**: espacio, memoria y conexión para que la web esté accesible.
- **La infraestructura**: la electricidad, la red y el hardware del proveedor.
- **Coste bajo**, sobre todo en los planes compartidos pensados para webs pequeñas.
- **Contratación sencilla**, sin gestión adicional para tenerlo activo.

Algunos planes añaden copias automáticas o un certificado de seguridad básico. Es el que hace que la web se abra con HTTPS y el navegador no avise de que no es segura. Fuera queda lo que funciona por encima del servidor: el gestor de contenidos, la plantilla y las extensiones. Tampoco entran la seguridad de la propia web ni su rendimiento.

Escribes al soporte del hosting porque tu web muestra un error. Lo normal es que te digan que el servidor funciona bien. Y suele ser cierto: el fallo está una capa más arriba.

## Qué añade un mantenimiento web completo

Todo lo que el hosting no cubre, alguien tiene que hacerlo. Un mantenimiento completo lo hace de forma planificada:

- **Actualizaciones del núcleo, la plantilla y las extensiones**, probadas antes de aplicarse. El método se detalla en [actualizar WordPress tú mismo o con mantenimiento profesional](/recursos/actualizar-wordpress-tu-mismo-o-con-mantenimiento-profesional/).
- **Copias de seguridad fuera del servidor**, con pruebas de restauración cada cierto tiempo para saber que sirven.
- **Seguridad de la propia web**: accesos, usuarios y extensiones que ya no se usan. Qué cubre una extensión y qué añade la revisión de una persona se compara en [plugin de seguridad o mantenimiento web gestionado](/recursos/plugin-de-seguridad-o-mantenimiento-web-gestionado/).
- **Optimización de la velocidad**: imágenes sin comprimir, extensiones que sobran o una caché mal configurada.
- **Supervisión.** Se comprueba que las páginas responden y que llegan los mensajes del formulario. Tras cada cambio, se revisa que no aparezcan errores.

Es habitual encontrar webs en un buen hosting que cargan despacio. El servidor hace su parte. Lo que falta es alguien que revise lo que funciona por encima. Basta una foto de portada subida tal cual sale de la cámara para que tarde en aparecer en el móvil de tu cliente.

## Las copias del hosting y las del mantenimiento

Muchos hostings incluyen copias automáticas, y son una buena base. Lo que te interesa saber es dónde se guardan, cuántos días se conservan y cómo se restauran.

Si las copias están en el mismo servidor que la web, un problema en ese servidor puede afectar a las dos. Es como guardar la llave de repuesto dentro de casa. Por eso el mantenimiento suele añadir una copia en un entorno externo y comprobar que se restaura bien.

Unas preguntas sencillas para saber qué tienes cubierto hoy:

- ¿Dónde se guardan las copias de la web y cuántos días se conservan?
- ¿Quién actualiza el gestor de contenidos y las extensiones?
- ¿Quién vigila que el certificado de seguridad y el dominio estén al día?
- ¿Quién lo resuelve si la web falla por un error de la propia web y no del servidor?
- ¿Alguien revisa la velocidad de carga?

Si varias respuestas son «nadie» o «no lo sé», esas tareas están pendientes de asignar. Puedes cubrirlas dentro o fuera de la empresa. Esa decisión se analiza en [mantenimiento web propio o externalizado](/recursos/mantenimiento-web-propio-o-externalizado/).

## Cómo decidirlo

| Criterio | Hosting básico | Mantenimiento web completo |
|---|---|---|
| Servidor, espacio y disponibilidad | Sí | Incluido o coordinado con el hosting |
| Actualizaciones del gestor y las extensiones | No incluidas | Incluidas y probadas |
| Copias verificadas fuera del servidor | Depende del proveedor | Incluidas |
| Seguridad de la propia web | No: cubre el servidor | Incluida |
| Optimización de la velocidad | Solo la del servidor | Incluida |
| Coste | Bajo | Cuota de servicio más amplia |

Para decidir rápido:

- **Hosting básico solo** si la web es [estática](/recursos/web-estatica-o-web-con-gestor-de-contenidos-cms/), apenas cambia y no es una vía de negocio activa.
- **Mantenimiento web completo** si la web genera contactos o ventas, o es la primera impresión que reciben tus clientes.
- **Los dos juntos**, en realidad. El hosting es la base necesaria y el mantenimiento, lo que la mantiene funcionando bien con el tiempo.
