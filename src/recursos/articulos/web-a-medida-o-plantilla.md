Montar una web con una plantilla puede llevar unos pocos días. Diseñarla y programarla a medida, unas semanas. La diferencia de plazo es real, pero no es la única que cuenta: también importa qué podrá hacer esa web dentro de un año, cuando el negocio haya crecido o haya cambiado.

Antes de comparar, conviene aclarar un término. «A medida» no significa sin gestor de contenidos: una web puede tener un diseño propio y, a la vez, un panel para que tu equipo la actualice. Esa es otra decisión, que se explica en [web estática o web con gestor de contenidos](/recursos/web-estatica-o-web-con-gestor-de-contenidos-cms/). Aquí la pregunta es si el diseño y la estructura se adaptan a tu empresa o es tu empresa la que se adapta a ellos.

## Lo que una plantilla resuelve bien

Es una opción razonable en muchos casos, sobre todo al empezar:

- **Coste inicial bajo**, porque no se diseña ni se programa desde cero.
- **Lanzamiento rápido**, útil para validar una idea o cubrir una necesidad urgente.
- **Suficiente para necesidades sencillas**: una web informativa, un catálogo básico o una página para una campaña concreta.

Su límite está en la propia estructura. Una plantilla está pensada para servir a muchos negocios distintos, así que el contenido se encaja en secciones que ya existen y lo que no viene de serie se añade con extensiones. Si el objetivo es tener presencia online pronto y sin complicaciones, una plantilla bien elegida cumple.

## Lo que aporta una web a medida

Cuando la web es una pieza activa del negocio, la diferencia empieza a notarse:

- **Diseño a partir de tu marca y tu mensaje**, sin encajar el contenido en un esquema pensado para otro tipo de empresa.
- **Código más ligero.** Sin funciones que la web no usa, suele cargar más rápido. Eso influye en el posicionamiento y en la [conversión de visitas en contactos](/recursos/diseno-web-centrado-en-estetica-o-en-conversion/).
- **Funciones específicas**: calculadoras, formularios con reglas propias, áreas privadas o integraciones con el ERP o el CRM. Si esa parte crece mucho, el proyecto pasa a ser más bien de [software a medida](/desarrollo-software-medida/).
- **Margen para crecer.** Se pueden añadir secciones y funciones sin reconstruir la web cuando el negocio cambia.

Al pasar de una plantilla a una web a medida, el cambio que más se nota no suele ser visual. Es la velocidad de carga y la facilidad para añadir cosas nuevas sin chocar con los límites de la herramienta original.

## Preguntas que conviene hacerse antes de elegir

- ¿La web tiene que generar contactos o ventas, o es sobre todo una carta de presentación?
- ¿Necesitas alguna función poco estándar, como un configurador, un área de clientes o una conexión con tu ERP o tu CRM?
- ¿Cuánto va a cambiar tu oferta en los próximos dos o tres años?
- ¿Te importa que tu web se parezca a la de otras empresas de tu sector?
- ¿Quién va a actualizar el contenido y con qué frecuencia?

Si la mayoría de respuestas apuntan a una web sencilla y estable, la plantilla tiene sentido. Si varias apuntan a crecimiento, integraciones o diferenciación, conviene valorar el desarrollo a medida desde el principio.

## Cómo decidirlo

| Criterio | Plantilla | Web a medida |
|---|---|---|
| Coste inicial | Más bajo | Más alto |
| Tiempo de lanzamiento | Días | Semanas |
| Diferenciación visual | Limitada | Amplia |
| Rendimiento y velocidad | Depende de la plantilla y de sus extensiones | Ajustado a lo que usa la web |
| Funciones específicas | Las que ofrecen las extensiones disponibles | Las que necesita el negocio |
| Crecimiento a futuro | Limitado por la estructura de partida | Previsto desde el diseño |

Una guía rápida:

- **Plantilla** si necesitas una web sencilla, pronto y con un presupuesto ajustado.
- **Web a medida** si la web es un canal de venta activo o necesita funciones que una plantilla no ofrece.
- **Empezar con plantilla y cambiar después** es una opción válida, siempre que se sepa desde el principio que llegará el momento de [rediseñar la web](/recursos/redisenar-la-web-desde-cero-o-evolucionarla-poco-a-poco/).
