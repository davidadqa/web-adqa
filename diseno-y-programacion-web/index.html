Diseño y programación web

¿Cómo se construye una web que transmite tu mensaje?

Una buena web empieza mucho antes del diseño. Primero hay que decidir qué quieres contar, a quién y en qué orden; después, qué tiene que poder hacer el visitante; y solo entonces darle forma visual y programarla.

Así trabajamos la web del Ajuntament de Vilanova i la Geltrú: aportamos la ordenación del contenido, la puesta en marcha de funcionalidades y el diseño gráfico, y en una segunda fase nos encargamos de la programación HTML y CSS de toda la web.

Podemos acompañarte en todas las fases o solo en las que necesites y, cuando la web ya esté publicada, seguir cuidándola con nuestro mantenimiento web.

  1. Ordenación del contenido

    Qué secciones necesita la web, qué va en cada una y cómo se llega a ellas. Es la base de una navegación sencilla.

  2. Funcionalidades

    Lo que la web tiene que permitir: formularios, buscadores, áreas de descarga, varios idiomas o la conexión con otras herramientas.

  3. Diseño gráfico

    La imagen de tu marca aplicada a cada página, legible y coherente en el ordenador y en el móvil.

  4. Programación HTML y CSS

    El diseño convertido en páginas reales, ligeras y bien estructuradas para que los buscadores las entiendan.

  5. Publicación y mantenimiento

    Dominio, alojamiento y correo configurados, y la web mantenida al día después del lanzamiento.

Una decisión técnica, explicada

¿Web estática o web con gestor de contenidos?

Las dos son buenas opciones. La elección depende de cuánto va a cambiar tu web y de quién la va a actualizar.

Web estática

  • Páginas HTML y CSS servidas tal cual: cargan muy rápido.
  • Menos piezas en el servidor, así que la superficie de ataque es menor.
  • Requiere poco mantenimiento técnico.

A tener en cuenta: cada cambio de contenido pasa por editar el código.
Encaja si tu web cambia poco y prefieres delegar las actualizaciones.

Web con gestor de contenidos (CMS)

  • Tu equipo publica noticias, páginas o documentos sin programar.
  • Admite blog, varios idiomas o catálogos con facilidad.
  • Se amplía con extensiones cuando aparecen necesidades nuevas.

A tener en cuenta: el gestor y sus extensiones necesitan actualizaciones periódicas.
Encaja si publicas a menudo y quieres hacerlo tú mismo.

Mantenimiento web

¿Qué incluye un mantenimiento web gestionado?

Una web no se termina el día que se publica. El gestor de contenidos, sus plantillas y sus extensiones reciben actualizaciones; los certificados se renuevan; el contenido envejece. Un mantenimiento web gestionado se ocupa de todo eso de forma planificada, para que tu web siga rápida, segura y al día.

Un plugin de seguridad aporta protección automática básica, como escaneos y bloqueo de accesos sospechosos. El mantenimiento gestionado añade lo que un plugin no puede aportar: personas con criterio técnico que prueban cada cambio antes de aplicarlo y revisan la web de forma periódica.

Plugin de seguridad o mantenimiento web gestionado

Lo que suele cubrir un mantenimiento gestionado

  • Actualizaciones probadas del gestor, las plantillas y las extensiones.
  • Copias de seguridad verificadas, para volver a una versión anterior si hace falta.
  • Certificado SSL y configuración del dominio, siempre en vigor.
  • Revisión periódica del rendimiento y de la seguridad de la web.
  • Cambios y mejoras de contenido o funcionalidad cuando los necesitas.

Respuestas claras sobre web y software a medida

Para el manager

¿Qué servicios web ofrece ADQA?

ADQA ofrece diseño y programación web, desarrollo de software a medida y mantenimiento web, junto con dominios, alojamiento, soluciones de correo electrónico y marketing digital. También implantamos Google Workspace y Microsoft 365, así que web, correo y herramientas de trabajo quedan en manos del mismo equipo.

¿Qué ventaja tiene encargar la web a tu proveedor de informática?

Que la web, el dominio, el alojamiento, el correo, los sistemas y la seguridad tienen un único responsable. Cuando hay que cambiar algo, por ejemplo un registro del dominio que afecta al correo, lo resuelve el mismo equipo, sin coordinar a varias empresas.

¿Cuándo compensa desarrollar un software a medida?

Cuando tus procesos tienen particularidades que un programa estándar no recoge bien, cuando necesitas que varias herramientas compartan datos o cuando adaptar el estándar exige más esfuerzo que construir lo que necesitas. Si ya tienes un programa que funciona, a menudo lo más sensato es ampliarlo o modernizarlo por partes.

¿Tenéis experiencia en webs de la administración pública?

Sí. Para el Ajuntament de Vilanova i la Geltrú aportamos la ordenación del contenido, la puesta en marcha de funcionalidades y el diseño gráfico de la web, y en una segunda fase nos encargamos de la programación HTML y CSS de toda la web. Además, somos la primera empresa del Garraf con certificación ENS en categoría ALTA.

Para el responsable técnico

¿Web estática o web con gestor de contenidos (CMS)?

Depende de cuánto y quién vaya a actualizarla. Una web estática carga rápido, tiene una superficie de ataque menor y requiere poco mantenimiento, pero cada cambio pasa por editar el código. Un CMS permite que tu equipo publique contenidos sin programar, a cambio de mantener al día el gestor y sus extensiones.

¿Dónde se alojan la web y las aplicaciones a medida?

Podemos alojarlas en nuestro datacenter propio y de proximidad, como hacemos con las aplicaciones corporativas de HITECSA, o en los servidores de tu propio CPD si lo prefieres. En los dos casos sabes dónde están y quién las mantiene.

¿Basta con un plugin de seguridad o conviene un mantenimiento web gestionado?

Un plugin de seguridad aporta protección automática básica, como escaneos y bloqueo de accesos sospechosos. Un mantenimiento gestionado añade a personas que aplican y prueban las actualizaciones, hacen y verifican las copias de seguridad y revisan la web de forma periódica. Son complementarios: el plugin no sustituye al criterio técnico.

¿Cómo se piden cambios o se comunican incidencias?

Con un único contacto en ADQA para todo. Además, nuestros servicios de instalaciones y mantenimiento se gestionan desde la extranet, un sistema de ticketing desarrollado por ADQA en el que das de alta incidencias y actuaciones, controlas su estado y las verificas en tiempo real.
